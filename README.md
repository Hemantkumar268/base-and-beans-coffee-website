# Base & Beans | Coffee Shop Website

A responsive coffee shop website built with HTML, CSS, JavaScript, and Bootstrap. The website features a modern design for showcasing coffee products, brewing gear, the brand story, customer reviews, and contact information.

## ✨ Features

- Responsive layout for mobile, tablet, and desktop screens
- Modern coffee shop landing page
- Navigation bar with a mobile navigation drawer
- Hero section with call-to-action buttons
- About section showcasing the brand and brewing process
- Coffee menu and brewing gear sections
- Customer reviews and FAQ section
- Contact information and footer
- Bootstrap components and Font Awesome icons
- Custom styling with CSS
- JavaScript for interactive UI elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. If required, use the Live Server extension in VS Code to run the website locally.

## 🎯 Project Goal

This project was created to practice responsive web design, CSS layouts, Bootstrap, website section structuring, and JavaScript-based interactivity.
